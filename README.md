# 你的故事，喵來說

靜態網站，可直接部署至 GitHub Pages。將 `index.html`、`assets/`、`.nojekyll` 放在儲存庫根目錄，於 Settings → Pages 選擇 main / root。

網站會將八題答案（包含可複選的故事標籤）以標準 HTML form POST 送至目前的 Google 表單；回覆保存在表單擁有者的 Google 帳號。瀏覽器無法跨網域確認 Google 是否實際接受回覆，請在部署後以自有測試資料送出一筆並到 Google 表單「回覆」核對。若題目被刪除重建，請重新取得 `entry.*` 欄位編號。表單若關閉回覆或要求登入，站內傳送可能失敗。頁面提供帶入答案的原始表單備援連結。

請留意：此頁面與原表單都會處理投稿者的個人資訊與故事；若要公開分享，請確認表單存取與隱私說明符合你的用途。
